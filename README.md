# AlumniConnect

AlumniConnect is a web-based alumni networking and mentorship platform developed using ShaktiDB.

## Features
- Alumni profile management
- Student profile management
- Mentorship requests
- Internship and job opportunities
- Search alumni by skills and company

## Technologies Used
- ShaktiDB
- Python (Flask)
- HTML, CSS, JavaScript
- GitHub
